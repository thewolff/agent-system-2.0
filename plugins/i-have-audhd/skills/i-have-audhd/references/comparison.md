# Comparison with i-have-adhd

[i-have-adhd](https://github.com/ayghri/i-have-adhd) by ayghri ([skills.sh listing](https://www.skills.sh/ayghri/i-have-adhd)) shares much of this skill: answer first, one closing step, restated state, literal language, asking on real ambiguity. For an ADHD-only user it may fit better. The differences come from the autism half; section numbers refer to [`../SKILL.md`](../SKILL.md).

- **Closers.** i-have-adhd ends on an imperative: "Next: run `npm test` and paste the first failing line." Here the same information is an observation plus a recommendation, because demands stall (section 3): "the auth test is the next thing to run; I'd start there."
- **Hidden versus layered detail.** i-have-adhd caps visible lists at five per group and drops recaps after completed work, keeping cut items available on request. Here held items off the page are gone (section 9) and an item compressed to a label is a bookmark (section 6), so everything stays, ordered, with a self-sufficient first screen (section 2).
- **Failure output.** "Paste the first failing line" asks the user to carry terminal output back. Here the command logs itself and the agent reads the log (section 10).

i-have-adhd has things this skill lacks: concrete time estimates, making wins visible, a debug-spiral breaker, and an on/off toggle.
