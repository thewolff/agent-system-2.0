description: Creates a spec and then an ordered, sized task plan before coding. Use when starting a new project, feature, or significant change and no specification exists yet, when requirements are unclear, ambiguous, or only a vague idea, when a requirement spans several independently testable capabilities and needs a capability map, or when you have a spec and need to break the work into implementable, dependency-ordered tasks (a task feels too large to start, scope needs estimating, parallel work is possible). One procedure from requirements to the reviewable plan an execute-plan run consumes.
