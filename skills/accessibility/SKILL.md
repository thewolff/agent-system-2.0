  Run a WCAG 2.2 AA accessibility audit on recently changed files or a specific
  file, and fix what it finds when asked. Analyzes React components, HTML structure,
  ARIA usage, CSS, and keyboard/focus patterns. Groups findings by severity and
  outputs a review under `.tmp/` in the workspace. Optionally opens a browser for
  visual checks (contrast, focus rings, screen reader). Use for any accessibility
  audit, review, check, or fix, in any repo.
